# Simple Classic Calculator

A basic calculator web app built with HTML, CSS, and JavaScript.  
Supports addition, subtraction, multiplication, and division with a clean and user-friendly interface.


## Live Demo

Check out the working calculator here:  
[Live Demo](https://samiramehzabin.github.io/Simple-Calculator/)


## Features

- Simple arithmetic operations
- Clear (C) button to reset
- Responsive buttons with hover effects
- Read-only display for input

## Usage

Click the buttons to enter numbers and operators. Press `=` to calculate the result. Use `C` to clear the display.
